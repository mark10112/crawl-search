# Real historical document benchmark — protocol frozen before provider outputs

Four sources, three unchanged native PDF pages each, twelve pages total. Thai: Fine Arts Department scanned contents table of collected Royal Gazette proclamations (Rama IV, not original Gazette facsimiles), and a yellowed printed edition of Rama V's daily royal chronicle. US: Census Bulletin 21 (1900), and Preservation of Newspaper Records (1934), including dense statistical tables. US sources retain their existing imperfect hidden OCR text. No invented text, sharpening, deskewing, new language metadata, or injected answer layer. PDF extraction preserves source page content; full source/page mapping and hashes recorded.

References.json consists of 24 manually transcribed sampled spans (top/later regions across all 12 pages) and 15 selected table row tuples. Transcribed from page renderings before provider runs. Historical Thai spelling retained; uncertain passages avoided. One AI visual reviewer, no independent human gold-standard adjudication. Metrics describe these samples, not whole-page CER or every table cell. Best-substring alignment is optimistic and cannot measure hallucinated text elsewhere. Inspect alignments/results manually before conclusions.

Main: current production local auto/balanced vs connected Firecrawl, each off/prime/hit. Four documents per provider per phase. Firecrawl maxPages=3 and files physically 3 pages to bound costs. Local max_chars=40000. Preserve existing text layers so the native-router test measures the shipped routing decisions, including accepting old OCR. Models warm; no hidden result cache when off. Supplemental: local forced OCR quality, mode=ocr, off only on same four native PDFs. This tests whether explicitly ignoring old text layers helps; does not replace production baseline. No production settings, token budgets, model weights or code changed to fit this test. Service LightOn max_new_tokens=1536, max_time=60s per page retained. Audit late-page anchor coverage and output lengths rather than treating ok=true as proof of completeness.

Scoring uses exact semiglobal Levenshtein alignment (edlib HW) to find each reference span in the full output. Unicode NFC, whitespace/Markdown decoration, typographic quotes/dashes and leader punctuation are normalized. CER is averaged equally over 24 sampled spans. Selected table rows use exact label+value tuple containment after presentation punctuation removal and Unicode decimal digit-value normalization (including Thai and Arabic-Indic); this is a strict row-tuple score including labels, not general cell accuracy or TEDS. It penalizes lost row/column association even if numbers exist somewhere else. Anchor presence threshold <=20% sampled CER is descriptive and does not guarantee complete pages.
